# Documentación del Hito 2

Fuentes de los diagramas, ADRs y diccionario de datos de Medical Printer.

| Carpeta o archivo | Contenido |
| --- | --- |
| `diagramas/c4-1-contexto.mmd` | Modelo C4, nivel 1: contexto |
| `diagramas/c4-2-contenedores.mmd` | Modelo C4, nivel 2: contenedores |
| `diagramas/c4-3-componentes.mmd` | Modelo C4, nivel 3: componentes del backend |
| `diagramas/uml-clases.mmd` | UML: clases de dominio |
| `diagramas/uml-secuencia-pedido.mmd` | UML: secuencia full stack de confirmar un pedido |
| `diagramas/uml-despliegue.mmd` | UML: despliegue en VPS con Docker |
| `adr/ADR-001` a `ADR-004` | Registros de decisiones arquitectónicas |
| `diccionario-datos.md` | Diccionario de datos de las 9 tablas |

## Cómo ver los diagramas

Los archivos `.mmd` están en Mermaid. Copia el contenido de cada uno en https://mermaid.live para verlo o exportarlo como imagen.
GitHub también renderiza Mermaid dentro de bloques de código con la etiqueta `mermaid` en archivos Markdown.
